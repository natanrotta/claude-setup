# docs/

Design rationale and decision logs for the `claude-setup` template. Not loaded by Claude Code at runtime — these are notes for humans maintaining the template.

## Files

- `decisions/` — ADR-style architecture decision records, numbered sequentially.

When making a non-trivial change to the template (new portable agent, change to the bootstrap interview, new template placeholder), drop an ADR here so future maintainers understand the why.
